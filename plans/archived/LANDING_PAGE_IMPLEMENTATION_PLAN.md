**バージョン**: 1.0

## 1. 概要

### 1.1 目的

AutoNovel の商用公開サイトとして、**商業的に最高品質**なランディングページ（LP）を構築する。  
「条件を入れたら、小説が届く」という価値提案を訴求し、訪問者を「かんたん執筆（Easy Mode）」「共創ウィザード」「Studio」のいずれかの入口へ誘導し、ユーザー登録・初回執筆までのコンバージョンを最大化する。

### 1.2 現状と課題

| 項目 | 現状 | 課題 |
|------|------|------|
| 公開 LP | 存在しない | 認証必須のアプリ画面（`/`, `/wizard`, `/studio`）しかなく、未登録ユーザーにプロダクト価値を伝える手段がない |
| ブランド発信 | GitHub README のみ | 商用サイトとしてのビジュアル・コピー・信頼構築要素（実績、料金、FAQ、導入事例）が欠如 |
| SEO/OGP | 未対応 | 検索からの流入、SNSシェア時のプリビュー最適化が未実施 |
| コンバージョン導線 | アプリ内完結 | 外部からの流入→登録→初回体験までのファネルが設計されていない |

### 1.3 成功定義（KPI）

| KPI | 目標値 | 計測方法 |
|-----|--------|----------|
| 初回ビューページの直帰率 | < 40% | GA4 |
| ヒーローCTAクリック率 | > 8% | GA4 イベント / Hotjar |
| 登録完了率（LP 経由） | > 12% | GA4 コンバージョン |
| LCP（最大コンテンツ描画） | < 2.5 秒 | Lighthouse / PageSpeed Insights |
| CLS（累積レイアウトシフト）| < 0.1 | Lighthouse |
| INP（インタラクション） | < 200 ms | Lighthouse |
| アクセシビリティスコア | 95 点以上 | axe-core / Lighthouse |

## 3. プロダクトポジショニングとコンセプト

### 3.1 ブランドコンセプト

> **「条件を入れたら、小説が届く」**  
> 企画から納品までを一連の流れでサポートする AI 小説支援ツール

- **ブランドトーン**: プロフェッショナル × 創造的 × 親しみやすい
- **キーワード**: AI 執筆、矛盾診断、8 専門オーディター、納品 ZIP、EPUB 出力
- **差別化要素**: 単なる生成AIラッパーではなく、「企画→執筆→監査→納品」を一貫してサポートするエンドツーエンドの小説制作プラットフォーム

### 3.2 ビジュアル方向性

| 要素 | 方向性 |
|------|--------|
| 全体雰囲気 | ダークモード基調（既存アプリとの整合性）に、アクセントカラーで商業感を演出 |
| イラスト | 抽象的なペン・本・光の軌跡をモチーフにした SVG アニメーション。重すぎない線画イラスト |
| 画像 | 既存の `docs/images/hero.svg`, `docs/images/entries.svg` を活用し、LP 用に最適化 |
| モーション | フェードイン・スライドアップ（既存 Tailwind アニメーションを再利用）。過度な動きは避け、読みやすさを優先 |

### 3.3 カラーパレット

既存アプリのダークテーマ（`#0f172a` slate-900 系）をベースに、商用 LP 用にアクセントを強化。

## 4. サイトマップと URL 構成

既存アプリ（認証必須）と公開 LP を共存させるため、以下の URL 構成を採用。

| パス | 用途 | 認証 | 備考 |
|------|------|------|------|
| `/` | **公開 LP トップ** | 不要 | 商業ランディングページ（新規作成） |
| `/lp` | LP エイリアス | 不要 | `/` へリダイレクト |
| `/pricing` | 料金プラン | 不要 | LP のセクションを独立ページ化 |
| `/features` | 機能詳細 | 不要 | LP のセクションを独立ページ化 |
| `/welcome` | 入口選択（オンボーディング） | 不要 | 既存。LP から遷移先 |
| `/`（アプリ）| かんたん執筆（Easy Mode） | **要** | 既存。`/app` へ移行検討 |
| `/wizard` | 共創ウィザード | **要** | 既存 |
| `/studio` | Studio | **要** | 既存 |
| `/login` | ログイン | 不要 | 既存 |
| `/register` | 新規登録 | 不要 | 既存 |

**移行方針**: 既存の `/` は認証必須の Easy Mode ページであるため、LP は別パス（`/lp` またはサブドメイン `lp.autonovel.example.com`）を検討。ただし、本計画書では **`/` を LP にし、既存アプリは `/app` 配下に移動** する方針を基本案とする（代替案として `/lp` も併記）。

> ※URL 構成の最終決定は、ステークホルダーとの合意後に確定すること。本計画書では `/` を LP と想定して記述する。

### 5.2 ヒーローセクション（ファーストビュー）

**目的**: 3 秒以内に「何のサービスか」「何ができるか」「次に何をすべきか」を伝える。

| 要素 | 内容 |
|------|------|
| スタブ（ eyebrow ） | `AI 小説執筆プラットフォーム` |
| H1（メイン見出し） | `条件を入れたら、小説が届く。` |
| サブ見出し | `企画から執筆、矛盾診断、納品まで。AI と共に創作する小説制作プラットフォーム` |
| CTA ボタン（プライマリ） | `無料で始める` → `/welcome` または `/register` |
| CTA ボタン（セカンダリ） | `機能を見る` → ページ内スクロール |
| 信頼バッジ | `8 専門オーディター監査 / EPUB 出力対応 / なろう・カクヨム形式対応` |
| ビジュアル | ヒーロー SVG アニメーション（既存 `docs/images/hero.svg` を最適化） |

**実装要件**:
- H1 は 1 つだけ。`data-testid="hero-headline"`
- CTA ボタンはファーストビュー内に 2 つ配置。スクロール不要でクリック可能
- モバイルではスタック、デスクトップでは横並び
- ビジュアルは LCP 対策として `loading="eager"`、`decoding="async"` を設定

各入口にカード形式で配置。ホバー時に微浮上＋アクセントカラーの枠線変化。

- CSS は Tailwind の PurgeCSS で未使用スタイルを除去
- プリロード: ヒーロー画像、`<link rel="preload">`

## 19. 移行計画（既存 `/` との共存）

**代替案**: LP を `/lp` に置き、既存 `/` はそのまま維持。この場合、ナビゲーションで `/lp` へ誘導する設計に変更。
