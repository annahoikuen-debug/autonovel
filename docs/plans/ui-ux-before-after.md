## 2. 画面ごとの比較

### 2.1 初回起動（`/`）

| 観点 | 実装前 | 実装後 |
|---|---|---|
| 最初に表示されるもの | かんたん執筆の入力フォーム | 入口選択（`/welcome`） |
| 「どれを使ったらよいか」の答え | なし。ヘッダーの 2 ボタンから推測するしかない | 3 入口が「誰向け・手順・おすすめ」で並ぶ |
| 選択の記録 | なし | `localStorage` に記録し二度と自動表示しない |
| 「あとで決める」導線 | なし | 1 クリックでかんたん執筆へ直行 |
| 迷った場合の脱出口 | なし | ロゴクリックでいつでも入口を選び直せる |

### 2.2 ヘッダー（3 入口ナビ）

| 観点 | 実装前 | 実装後 |
|---|---|---|
| ボタン数 | 5（モード 2 + 設定 3） | 6（入口 3 + 設定 3） |
| 入口ラベル | 「⚡ かんたんモード」「🚀 上級者 Studio」 | 「⚡ かんたん」「✨ 共創ウィザード」「🚀 Studio」 |
| 各ボタンの説明 | なし（ホバーしても出ない） | 1 行の説明を常時表示 |
| 現在地の把握 | Border 色の変化のみ | 色 + 背景 + 影でハイライト、`aria-current="page"` |
| ウィザードへの到達 | モーダルで別コンポーネントを起動 | 通常のルート遷移 |
| レスポンシブ | なし | 900px 未満で説明文を隠す、640px 未満で等幅配置 |

### 2.3 かんたん執筆（`/`）

| 観点 | 実装前 | 実装後 |
|---|---|---|
| モード選択の表示 | 3 モードが常に横並び | 「かんたん執筆」1 個のみ。残りは「もっと細かく設定する」で展開 |
| 初回表示の選択肢数 | 3 | 1 |
| 監視パネル | PDCA / DAG が常に占有 | 「執筆の進み具合を詳しく見る」で展開 |
| Studio への移行 | 昇格ボタンで直接遷移、またはheuモーダル（2 通り） | 昇格 → 移行オーバーレイ → Studio（1 通り） |
| Studio 機能の予告 | ネイティブ `alert()`（画面がロックされる） | 閉じられるモーダル（そのまま Studio へ進める） |

### 2.4 共創ウィザード（`/wizard`）

| 観点 | 実装前 | 実装後 |
|---|---|---|
| 現在地の表示 | なし。Step 内部のテキストのみ | 画面上部に 3 ステップの常設インジケータ（sticky） |
| ステップ数 | テキストから推測 | 「1 / 3 ステップ」と明示 |
| 執筆済みの話数 | なし | 「執筆済み N 話」を表示 |
| Step3 の本文 | **表示されない**（話数だけ増える dead-end） | SSE の `content` を state に蓄積して表示 |
| Step3 の出口 | なし | 「もう 1 話書く」「Studio で細部を手入れする」の 2 つ |
| 前のステップへの戻り | Step2 内のみ | 全ステップから「前のステップ」ボタン |
| ヘッダーからの到達 | ルートとモーダルの 2 つ | ルート 1 つ |

### 2.5 Studio（`/studio`）

|---|---|---|

## 5. 対象ユーザー視点での変化

### 小説は初めて書く人

| 実装前 | 実装後 |
|---|---|
| 「⚡ かんたんモード」と「🚀 上級者 Studio」の違いが分からない | 初回に 3 入口が説明つきで提示され、どれか選べる |
| 上級向けの設定が最初から横並びに並ぶ | 必要最低限だけ表示され、残りは自分で開く |
| 画面が並列表示され、違いが分からない | 常時ハイライトされるので「今どこにいるか」が分かる |
| 機能の説明を製品の説明書に問い合わせる | ボタン横に 1 行で書いてある |
| 書き終えたあとの先が分からない | どこへも行けるかが明示されている |

### 中級以上の書き手（複数作品）

| 実装前 | 実装後 |
|---|---|
| Studio 内で tabs 5 個が同列で、何を選ぶか迷う | 目的別 3 グループに分かれていて、選ぶ基準が分かる |
| ルートの重複で UI が二重に出る | 定義が 1 か所に集約されている |

---

## 6. 結論

- **致命バグ（Tailwind 未適用・ウィザード表示破損）は解消**され、画面が壊れた状態から正常表示に復帰
- **「どこから始めるか」と「終わったらどうするか」が全ての画面に明示**され、入口と出口が繋がった
- **段階開示により初期画面の選択肢が 1/3 に削減**され、非技術者の認知負荷が下がった
- **品質ゲートは全て通過**（型検査 0 エラー / テスト全通過 / ビルド成功）
