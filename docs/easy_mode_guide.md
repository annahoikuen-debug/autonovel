# AutoNovel ユーザーガイド（入口の歩き方）

バージョン: 2.0
対象: AutoNovel の 3 つの入口（かんたん執筆／共創ウィザード／Studio）

---

## はじめに — 3 つの入口

AutoNovel には 3 つの入口があります。**どれも同じ作品に書き足していく**ので、
あとから別の入口へ移っても内容は失われません。

| 入口 | URL | 向いている人 | 手順 |
|---|---|---|---|
| ⚡ かんたん執筆 | `/` | はじめて書きたい人 | 手順 2 つ（約 1 分） |
| ✨ 共創ウィザード | `/wizard` | 物語の骨組みから作りたい人 | 手順 3 つ |
| 🚀 Studio | `/studio` | 仕上げや設定を担う人 | 既存作品からすぐ |

### 初回起動時の入口選択（/welcome）

はじめて起動すると `/welcome`（入口選択）が表示されます。
3 つの入口が「誰向け・何ができるか・手順はいくらか」の形で並ぶので、
理解了うえで好きなものを選んでください。「あとで決める」を押すと
かんたん執筆へ直行します。選んだ内容はブラウザに保存され、2 回目以降は
そのまま各入口へ着地します。

入口を選び直すには、画面左上のロゴ（AutoNovel）をクリックしてください。

### ヘッダーの入口ナビ

どの画面にいても、画面上部の `⚡ かんたん` / `✨ 共創ウィザード` / `🚀 Studio` から
3 つの入口へ移動できます。いまいる入口は色付きでハイライトされます。

---

## 導線の全体像（1 周して覚える）

```
/welcome （入口を選ぶ）
   │
   ├──→ ⚡ かんたん執筆 ────→ 「Studio へ昇格」──→ 🚀 Studio
   │
   ├──→ ✨ 共創ウィザード ──→ Step3 本文執筆 ──→ 🚀 Studio で細部編集
   │
   └──→ 🚀 Studio（既存作品をそのまま開く）
```

- かんたん執筆から Studio へ移るときは、必ず「移行オーバーレイ」を経由します。
  そこで「いまからできること」を確認してから移動するので、迷いません。
- 共創ウィザードの Step3 には「もう 1 話書く」と「Studio で細部を手入れする」の
  2 つの出口があり、書き終えたあとも切り抜けません。

---

## ⚡ かんたん執筆（Easy Mode）

かんたん執筆は、AI小説生成を **2 ステップ** で始められる初心者向けモードです。
詳細な設定は不要で、以下のいずれかの方法で執筆を開始できます:

1. **企画ガチャ** — ボタン1つで3つの物語案をランダム生成
2. **直接入力** — キャラ設定と冒頭テキストを入力して即執筆（既定）

「もっと細かく設定する」を押すと、逆算プロットビルダーなどの上級向けモードが
表示されます。はじめての方は既定のままで十分です。

### 段階開示 — 必要なものだけ見える

- **制作設定の上部**には「かんたん執筆」だけが表示され、上級向けの選択肢は
  折りたたまれています。
- **PDCA / DAG 監視パネル**は常時表示されず、画面下の
  「📡 執筆の進み具合を詳しく見る」を押したときだけ開きます。
- **「👀 Studio 機能チラ見せ」**は画面をロックするアラートではなく、
  閉じられるモーダルとして表示され、そのまま Studio へ進めます。

## 主要機能

### 1. 企画ガチャ 🎲

**使い方:**
1. 「🎲 企画ガチャ」ボタンをクリック
2. 3つの物語案（王道・変化球・ダーク）がモーダルで表示される
3. 気に入った案をクリックして選択

**選択後の自動処理:**
- 選択した案の主人公サマリーがキャラ設定に反映
- プランの方向性（タイトル・概要・魅力点）が本文シードに挿入
- 自動的にかんたん執筆が開始される

**案のタイプ:**
| タイプ | 色 | 説明 |
|-------|-----|------|
| `royal` (王道) | 金色 | 定番の王道展開 |
| `curveball` (変化球) | 青色 | 予想を裏切る展開 |
| `dark` (ダーク) | 紫色 | 重厚でシリアスな展開 |

### 2. ダイジェスト 📖

**前提:** 先にガチャを回してプランを生成しておく必要があります。

**使い方:**
1. 「📖 ダイジェスト」ボタンをクリック
2. 選択したプランから以下が高速生成される:
   - 全体あらすじ
   - 第1話の本文
   - クライマックスプレビュー
3. 結果がモーダルで表示され、内容を確認できる

### 3. リアルタイム速筆 (SSE) ⚡

**使い方:**
1. キャラ設定と冒頭テキストを入力
2. 「⚡ リアルタイム速筆 (SSE)」をクリック
3. 画面下部の「リアルタイム執筆プレビュー」で生成中の本文をリアルタイム確認

**プレビューの特徴:**
- モノスペースフォントで視認性向上
- リアルタイム文字数表示
- 自動スクロールで最新部分を追従表示

**接続エラー時:**
- 自動的に再接続を試みます（最大2回、1秒間隔）
- 再接続中は「再接続中 (1/2)」のようにステータス表示
- 全リトライ失敗時は明示的なエラーメッセージを表示

**操作:**
- 執筆中は「⏹ 中止」ボタンでキャンセル可能

### 4. かんたん執筆開始 🪄

**使い方:**
1. キャラ設定と冒頭テキストを入力
2. 「🪄 かんたん執筆開始」をクリック
3. 非同期で生成が開始される（バックグラウンド処理）
4. 完了後、本文がエディタに反映される

### 5. Studioモードへの昇格

**使い方:**
1. ガチャ → ダイジェストで作品を作成
2. エクスポート後、「昇格 (Promote)」を実行
3. `/studio/{book_id}` へリダイレクトされ、Studioモードに引き継がれる

**Studioモードで使えるようになる機能:**
- リアルタイム品質スコア表示
- シーン別プレビュー
- AIによる詳細な推敲サポート
- プロットビジュアライザー
- ブランチング（分岐執筆）

## エラーと対処法

| エラーメッセージ | 原因 | 対処法 |
|----------------|------|--------|
| 「ガチャの生成に失敗しました」 | LLMタイムアウト等 | しばらく待ってから再試行 |
| 「先にガチャを回してプランを生成してください」 | ダイジェストの前提不足 | 先にガチャを実行 |
| 「利用可能なプランが見つかりませんでした」 | プランデータ不正 | ガチャを再実行 |
| 「接続エラー (3回試行)」 | ネットワーク/サーバー障害 | 接続を確認して再試行 |
| 422 バリデーションエラー | 入力形式不正 | 入力内容を確認 |

## よくある質問 (FAQ)

**Q: ガチャの結果を保存できますか？**
A: ガチャ結果は選択後にキャラ設定・本文シードへ自動反映されます。モーダルを閉じても選択済みの反映内容は失われません。

**Q: API キーは必要ですか？**
A: 開発環境ではデフォルトのモックアダプターが使用されます。本番環境で実LLMを使用する場合は、設定パネルから API キーを入力してください。

**Q: 執筆中にブラウザを閉じても大丈夫ですか？**
A: リアルタイム速筆（SSE）はブラウザを閉じると中断されます。かんたん執筆開始（非同期タスク）はサーバー側で継続され、`/easy_mode/status/{task_id}` で結果を取得できます。

**Q: 生成した作品をダウンロードできますか？**
A: はい。エクスポート機能で ZIP パッケージ（本文・設定・プロット・JSON）をダウンロードできます。
