# ブラウザデモ（かんたんモード）

インストール不要・サーバー不要で AutoNovel の主要機能を体験できる静的デモです。

## 起動方法

1. `web/demo/index.html` を Chrome / Edge / Firefox などで **ダブルクリック** する
   （ファイルとして直接開けば動きます。サーバーは不要です）
2. 画面右上の「**チュートリアルモード**」を ON にすると、各ステップの説明が表示されます

## 体験できる機能（5ステップ）

| ステップ | 内容 | 操作 |
|---|---|---|
| 1 | 企画ガチャ | 「企画ガチャを引く」でジャンル別の物語案をランダム生成し、1つ選択 |
| 2 | 逆算プロットビルダー | 4つの質問に答えるだけでプロット構造とエピソード別あらすじを生成 |
| 3 | キャラクター設定 | 主人公・ヒロイン・敵の性格・目的・口癖を設定 |
| 4 | かんたん執筆 | 選択したプロットから本文を生成（モック） |
| 5 | 完成・エクスポート | 全文を表示し、納品パッケージ（ZIP）をダウンロード |

> このデモは **モック実装** です。実 LLM による生成は行いません
> （API キー不要・ネットワーク不要で動かせることを優先しているため）。
> 実モデルでの執筆は「② Windows ワンクリック起動」または「③ Docker Compose」を使ってください。

## ファイル構成

```
web/demo/
├── index.html      # 画面（5ステップの UI）
├── style.css       # スタイルシート
├── script.js       # 画面遷移・モック生成ロジック
├── mock-data.js    # 企画ガチャ／プロット／キャラクターのモックデータ
└── README_DEMO.md  # このファイル
```

## 補足

- 実モデルでの動作確認は `README.md` の「② Windows ワンクリック起動」 /
  「③ Docker Compose」を参照してください。
- デモの画面文言や動作を変更したい場合は `index.html` と `script.js` を編集すれば
  そのまま反映されます（ビルド工程は不要です）。
